# 制作参考

## 内容与时间轴契约

内容至少声明章节 ID、标题、旁白、可视目标、来源；按需声明公式、要点、音乐类别和逐句翻译。实现中用 TypedDict、dataclass 或静态类型定义这些接口。

时间轴由音频构建器独占写入，使用秒为单位，声明语言、总时长、章节区间与字幕区间。字幕结构为 `start: number`、`end: number`、`text: string`、`translation?: string`。所有消费者使用同一时间原点。

每段 PCM 时长由 `采样帧数 / 采样率` 测量，加上明确的片头、章节留白和过渡。各语言独立测量。英文版的中文翻译使用英文分句和时间轴，不能套用中文版的字幕时间。

在合成前固化分句列表并检查翻译数量。通用句号分割会误切缩写、小数和参考编号，长句也可能超出字幕区域。需要修正时同时修改配音分句与字幕输入。内容变化后按依赖重建，避免复用同名但已失效的音频。

## 内容可视化

- 内容依赖图说明“理解 B 之前需要 A”；涉及主张时另有文献关系图，说明方法联系、共享对象、对照关系或有证据的继承关系，见 [evidence-rigor.md](evidence-rigor.md)。
- 数学动画保持假设可见。例如水平集示例应说明正则性条件，局部近似与全局结论分别呈现。
- 每个动画变化对应旁白中的一个可解释变化，例如点移动、坐标变换、约束收紧或候选轨迹插值。
- Canvas 文字层与 Three.js 场景使用一致的画幅和安全区。字幕区预留两种语言的总高度；长句优先重新分句或调整版式。
- 字体就绪后再测量和截图。检查实际字形、上下标、公式边界以及三维标签的遮挡。

## 语音与混音

本地模型先确认语言、声音许可、磁盘空间和推理依赖。声音预览包含真实脚本的专有名词、数字和缩写；只检查日常问候无法代表正式内容。

按句或短段保存 PCM，并记录模型来源、权重校验和、音色、语速、采样率、各段时长与峰值。模型与前端版本共同影响发音，均纳入记录。合成环境与编码环境分开时通过显式文件格式传递音频。

音乐使用原创合成或许可明确的素材。将音乐结构与章节语义类别关联，减少对章节编号的耦合。以旁白包络控制音乐避让，采用快速降低、较慢恢复和平滑淡入淡出，避免明显抽吸感。

电平观测注明测量对象与单位：RMS dBFS、峰值 dBFS、LUFS 各有含义；源 WAV 的结果也不能直接当作最终 AAC 的结果。片头、密集讲解、章节过渡和片尾分别试听。最终编码后复核听感与同步。

## 渲染与编码

播放器以 `draw(t)` 或等价显式接口支持预览与录制。局部场景状态可由章节起点和时间推导；随机过程使用固定种子。手动跳转与连续播放在同一时间应得到一致画面。

先测短片的吞吐与实际帧时间戳。实时捕获的帧率设置并不保证每帧都被录到；回调计数也不等于编码帧数。若使用速度倍率 `k`，记录它并用 `setpts=k*(PTS-STARTPTS)` 恢复视频时间，音频沿自然时间轴封装。吞吐不足时调整录制方案并重新验证样片。

大媒体通过有序分块写入本地文件，检查每块传输结果及最终文件可解码性。分块传输只解决传输尺寸问题；若浏览器仍聚合整个 Blob，内存使用仍随片长增加，应实测。

H.264、yuv420p、AAC 与 faststart 是常用交付组合；画幅、帧率、码率按需求配置。显式选择视频、音频、章节流，避免旧音轨或错误语言混入成片。仅截断到目标时长可能掩盖提前结束的流，应分别检查流时长和片尾。

交付通常还需要一张封面/缩略图帧，供播放入口和分享场景使用。可以取章节关键帧或单独渲染一帧；连同成片一起登记路径、尺寸和来源时间点到交付记录。

## 观测清单

| 对象 | 记录与检查 |
|---|---|
| 内容 | 定义与依据的来源；内容顺序；图谱连线含义 |
| 配音 | 分句数量、缺失/空片段、时长分布、采样率、声道、峰值、实际试听范围 |
| 字幕 | 译文数量、时间单调性、正时长、总时长范围、换行及边界；烧录与 SRT 对应 |
| 画面 | 全章代表帧、拥挤帧、公式/字形、几何含义、浏览器错误、字体就绪状态 |
| 渲染 | 实际耗时、倍率、流帧率与时间戳、文件大小、内存观测若可获得 |
| 成片 | 双流完整解码、实际视频抽帧、片头/中段/片尾同步、声音及章节元数据 |
| 播放入口 | 每个语言能加载、播放、跳转，尺寸/时长正确，字幕入口指向对应文件 |

英文画面的未翻译文字检查应将有意保留的中文翻译区排除。单张截图没有字幕可能是合理留白，应对照时间轴判断。程序成功退出只能证明相应程序执行成功，不能替代画面检查或试听。

## 修改影响矩阵

| 变更 | 需要重建与检查 |
|---|---|
| 仅外置 SRT 文案 | 对应 SRT、字幕语义与时序；现有烧录字幕仍保持旧文案 |
| 烧录字幕或逐句翻译 | 字幕数据/时间轴构建、画面预览、渲染、编码、成片验证；可保留不变的语音片段 |
| 旁白或音色 | 相关语音片段、该语言完整时间轴与混音、字幕、渲染、编码、同步验证 |
| 几何、公式、画面布局 | 受影响预览、视频渲染、编码与画面验证；语音与混音可复用 |
| 仅背景音乐 | 混音、最终音轨封装与音频/同步验证；时长不变时复用已有视频画面 |
| 章节增删或重排 | 核对片段身份与缓存；重建时间轴、配乐、字幕、画面及章节元数据 |

具体脚本可能一次重建多个产物；使用其真实入口，避免凭空假设存在局部构建开关。只有与有效输入一致的缓存才可复用。

重建结果写入新路径或新版本标识，不默默覆盖此前已交付的文件；需要替换已交付版本时，先明确确认再覆盖。

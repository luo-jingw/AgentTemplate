# 主张与证据严谨性

可选模块。仅当本片内容包含需要校准强度的事实或学术主张时读取和启用——例如陈述"某结论成立""某方法优于另一方法""某现象的原因是……"这类可被证伪的说法。纯演示、纯视觉展示或不作此类断言的内容跳过本文件；`SKILL.md` 与其余 reference 文件不依赖这里的任何字段，不需要为它们留空占位。

判断在 P0 做一次即可，结果记入 `plan.md` 的视频部分。

## 主张身份

`content/storyboard.md` 每章接口的 `claims` 字段记录：主张 ID、表述、身份、来源位置或假设依据。

身份取值：`definition / established_result / analogy / hypothesis / measured_result`。

- `definition`：按来源记录的定义本身，不需要额外证据。
- `established_result`：记录适用条件，不能脱离条件单独引用结论。
- `measured_result`：链接真实测量，不能用示意图代替实测数据。
- `analogy`：写明对应关系，以及不能从这个类比推出的结论。
- `hypothesis`：明确标注尚未验证，旁白与画面都不能将其表现为确定结论。

来源记录文献/文档标识、链接或本地路径、页码/章节和支持的具体表述。"来自调研"不是可追踪位置。

旁白、公式、画面和引用连线必须表达同一强度的主张。常见错误：画面展示了连续双射，旁白却直接称为同胚——应检查是否已建立逆映射连续性或等价的充分条件，而不能因为两个图形"看起来可变形"就通过。

## 文献关系图

与内容依赖图分开维护，图的性质不同：内容依赖图回答"理解 B 之前需要先懂 A"，文献关系图回答方法/结果/论文之间的关系。

节点是具体的方法、结果或文献。边的含义必须显式声明，例如"改进自""共享前提""在条件 X 下等价""作为对照基线"；笼统的"相关工作"不是一条边的含义。每条边能从来源找到支持该具体关系的表述。

## 审查中的检查

- **主张强度**：对照来源和主张身份，检查"可能"是否被口播或动画变为"必然"。
- **文献图正确**：每类边有含义，来源能支持继承、比较或相邻关系的具体说法。

两项不通过均回 P1/P2 修订文案或分镜。

## 翻译中的检查

跨语言版本的模态词（条件、否定、可能性）和主张身份必须保持一致。这不是逐字直译的问题——即便两种语言用词不同，断言的确定性也不能因翻译而增强或减弱。

# Documentation

`docs/` is the repository's verified world model.

Allowed content:
- architecture;
- module responsibilities;
- interfaces;
- state ownership;
- runtime flows;
- measured profiling results;
- verified technical decisions.

Do not store:
- TODO items;
- unresolved hypotheses;
- future optimization ideas;
- temporary plans;
- session summaries.

Use:
- `plan.md` for approved work;
- `issues.md` for unresolved problems;
- `opportunities.md` for future improvements.

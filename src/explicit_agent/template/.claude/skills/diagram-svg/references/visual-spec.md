# 视觉规格

## 画布与网格

| 项目 | 规定 |
|---|---|
| 画布 | `viewBox="0 0 680 H"`，宽度固定 680，`width="100%"`，H 按内容计算 |
| 安全区 | x 在 40–640 之间，四周至少留 30–40 的空白 |
| 高度 | H = 最低元素底边 + 20～40，不要留大片空白 |
| 五列布局 | 框宽 104，间距 18：x = 44, 166, 288, 410, 532（中心 96, 218, 340, 462, 584） |
| 两列布局 | 框宽 240，左列 x=80，右列 x=360（中心 200, 480） |
| 三列布局 | 框宽 180，x = 50, 250, 450（中心 140, 340, 540） |
| 横跨整行的框 | x=44，宽 592 |
| 行间距 | 框与框之间垂直留 24～36，放箭头 |

方向：主数据流一律**自上而下**；对比、流水线类图可以**自左向右**。不要在同一张图里混用两种方向，也不要画环形布局。

## 颜色语义

全文固定使用以下含义（可按项目调整，但同一份文档内必须一致）：

| 颜色类 | 用途 | 浅色：填充 / 描边 / 标题 / 副标题 | 深色：填充 / 描边 / 标题 / 副标题 |
|---|---|---|---|
| `g-box`（中性） | 输入、输出、普通处理步骤 | #FFFFFF / #B4B2A9 / 正文色 / 次要色 | #232321 / #5F5E5A / 正文色 / 次要色 |
| `g-gray` | 冻结的模块、外部编码器、对照基线 | #F1EFE8 / #888780 / #444441 / #5F5E5A | #444441 / #B4B2A9 / #F1EFE8 / #D3D1C7 |
| `g-teal` | 专属/独立的层、条件输入 | #E1F5EE / #0F6E56 / #085041 / #0F6E56 | #085041 / #5DCAA5 / #E1F5EE / #9FE1CB |
| `g-purple` | 共享主干、核心计算、注意力 | #EEEDFE / #534AB7 / #3C3489 / #534AB7 | #3C3489 / #AFA9EC / #EEEDFE / #CECBF6 |
| `g-coral` | 输出头、最终结果、需要强调的产物 | #FAECE7 / #993C1D / #712B13 / #993C1D | #712B13 / #F0997B / #FAECE7 / #F5C4B3 |
| 虚线框 | 被丢弃的输出、被屏蔽的位置、填充区域 | 无填充，描边 #B4B2A9，`stroke-dasharray: 3 3` | 同左，描边 #5F5E5A |

规则：
- 框内文字必须使用同色系的深色（标题用"标题色"，副标题用"副标题色"），不要用纯黑或通用灰。
- 标题和副标题必须是两个不同的色阶，只靠字重区分会显得平。
- 颜色不能是唯一的区分手段：被屏蔽 / 丢弃的位置同时用虚线表示。

## 元素规格

| 元素 | 规格 |
|---|---|
| 单行框 | 高 44，`rx="8"`，标题居中 |
| 双行框 | 高 56，`rx="8"`，标题 y = 框顶 + 19，副标题 y = 框顶 + 38 |
| 小方块（矩阵 / 序列） | 40～52 见方，`rx="4"` |
| 描边 | 0.5～0.7 |
| 标题字 | 14px，字重 600，class `th` |
| 普通字 | 14px，class `t` |
| 副标题 / 图例 / 轴标签 | 12px，次要色，class `ts` |
| 字号 | 只用 14 和 12 两档，不出现其它字号 |
| 文字对齐 | 框内文字一律 `text-anchor="middle" dominant-baseline="central"`，y 取该行的中心 |
| 箭头 | 线宽 1.2，次要色，开口折线箭头（marker），箭头尖端距目标框 3px |
| 折线箭头 | 分叉或绕行时用 L 形 `<path d="M x1 y1 L x1 ymid L x2 ymid L x2 y2" fill="none">` |
| 残差 / 旁路 | 虚线箭头 `stroke-dasharray="4 3"`，从框的侧面绕出 |
| 图例 | 图底一行 12px 文字，如"灰：冻结编码　青：专属层　紫：共享层　珊瑚：输出头" |

文字宽度估算（避免溢出）：14px 汉字约 14px 宽，14px 英文约 8px / 字符，12px 汉字约 12px 宽。框宽 ≥ 最长一行文字宽度 + 24。

# 页面结构

## 两种模式，一份 HTML

- **宽屏（≥700px，"演示模式"）**：JS 在 `<html>` 上加 `paged` class。所有 `.slide` 变成绝对定位、固定设计宽度（`DW=1200`），按窗口大小整体缩放铺满（CSS 变量 `--k`），同一时刻只有一张 `active`，左右翻页时做位移淡入淡出。右下角出现翻页按钮（上一页/下一页/全屏）和底部进度条。
- **窄屏（<700px）**：保持普通的长滚动布局，`scroll-snap` 让每页卡片贴齐视口；没有翻页按钮，用户直接滚动。

**不要为这两种模式单独写两份文件**——内容只写一次，模式切换是纯 CSS/JS 行为，`resize` 事件会在窗口跨越 700px 阈值时自动切换。

## 翻页与导航

支持：方向键（← → ↑ ↓）、空格（下一页，Shift+空格上一页）、Home/End（跳首尾）、PageUp/PageDown、鼠标滚轮（带防抖，一次滚动只翻一页）、触摸左右滑动、点击翻页按钮、`F` 键或全屏按钮切换浏览器全屏、URL hash（`#3` 直接跳到第 3 页，刷新/分享链接不丢页码）。

这些行为全部由模板自带的脚本处理，正常情况下不需要改动；新增页面只需要在 `<main class="deck">` 里按顺序加 `<section class="slide" id="...">`，翻页逻辑会自动识别新的页数。

## 每页结构

```html
<section class="slide" id="稳定的英文id">
  <header>
    <span class="kicker">分组标题 · 第几部分</span>
    <span class="pg mono">03 / 08</span>
  </header>
  <h2>这页回答的具体问题</h2>
  ... 内容 ...
</section>
```

- `id` 要稳定（之后改页序时 URL hash 导航不依赖它，但便于引用和调试）。
- `kicker` 是分组标签，不是页面标题；`h2` 才是标题，必须是能回答"这页讲什么"的完整句子，不要写成关键词堆砌。
- 页码 `01 / 08` 手动维护，和页面增删同步更新；不是必须精确到自动计算，但不能和实际翻页按钮显示的进度条矛盾太久。

## 封面页

第一页固定承担：项目/主题名（`kicker`）、标题句（一句话概括结论，不是泛泛的项目名复述）、日期或截止时间戳（`subtitle mono`）、可选的分节导航（`.agenda`，列出后续每节的编号和标题，方便读者判断要不要跳读）。

## 首次进入动画

窄屏滚动模式下，每张卡片首次进入视口时有一次淡入+上移的入场（`IntersectionObserver` 触发，一次性，不会反复播放）；曲线图的线条同时做一次描边动画，散点和预测线延迟一点淡入，制造"先看到趋势、再看到细节"的阅读顺序。宽屏演示模式翻到某页时效果相同，由 `go()` 直接调用。

`prefers-reduced-motion: reduce` 时所有动画被跳过，元素直接以最终状态显示——这是无障碍要求，不要绕过。

## 打印 / 导出 PDF

`@media print` 规则会关掉翻页定位和动画，把每张卡片按正常文档流依次排列、每页强制分页（`break-after:page`）。固定用浅色配色打印（参考 `diagram-svg` 的"导出静态图"一节），不要依赖系统深色模式打印。

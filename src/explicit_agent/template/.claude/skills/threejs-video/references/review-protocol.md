# 审查与修订协议

P1/P2 检查内容；P3 检查代表样片；P5 检查全章预览；P7 检查最终编码文件。修订后只重新检查受影响内容及它的下游依赖。审查与修订分为两个明确步骤，审查结果不能被修订者的自述替代。

## 审查输入

- 当前范围、受众和交付要求。
- 分镜中的理解目标、画面事件；涉及主张时另含主张依据。
- 当前语言脚本和时间轴。
- 与检查阶段相符的预览或真实成片。
- 本版本的观测记录，及历史未关闭问题。

缺少分镜的已有视频，按本次修改范围核对现有脚本与来源；无需为一次字幕排版修改追建无关文档。

## 问题记录

写入 `build/<lang>/qa/review.md`，跨语言内容问题可由一个指定的共用审查文件拥有，语言记录引用其 ID。

```text
issue_id: V-001
location: chapter_id / 句子序号 / 成片时间 / 相关文件
observation: 实际看到或听到的具体不一致
expected_relation: 来自需求、来源或分镜的正确关系
evidence: 截图/音频区间/观测 JSON 路径及输入校验和
impact: 对理解、准确性或播放造成什么影响
return_to: P1…P6 中最早需要修改的阶段
affected_outputs: 需要重建的文件
status: open | resolved | unverified
resolution: 改动位置与重新检查的证据
```

`unverified` 表示缺少实际检查证据，不表示没有问题。记录已有依据可以定性的问题，不把主观偏好伪装成确定缺陷。不得仅用“效果不好”“不够专业”作为可执行修订项。

## 内容审查

| 检查 | 具体动作 | 常见返工 |
|---|---|---|
| 前置闭合 | 在术语首次使用处向前查找定义，或核对是否属于受众已知内容 | 回 P1 调整顺序或补桥接 |
| 定义完整 | 对照素材检查量词、条件、局部/全局、可逆/单射等区别 | 回 P2 修订文案与公式 |
| 例子有效 | 检查画面对象确实满足所讲定义；反例确实违反对应条件 | 回 P1/P5 |
| 主张强度与文献图（涉及主张时） | 按 [evidence-rigor.md](evidence-rigor.md) 检查 | 回 P1/P2 |
| 效果达成 | 遮住旁白文案，依据画面与口播能否达成本章的 `outcome_check` | 补解释步骤或重做视觉事件 |
| 双语一致 | 按 chapter_id 核对条件、否定、可能性与术语，而非要求逐字直译 | 回 P2 |

不涉及主张的内容，审查聚焦画面与旁白是否达成 `outcome_check`，不要求存在可证伪的结论；涉及主张时参见 evidence-rigor.md 的具体检查项和错误示例。

## 视听审查

选择全部章节的关键解释帧，加上文字最密、物体遮挡、转场和字幕最长的位置。成片再抽查片头、中段、片尾及已修订片段，记录实际时间，而不是只记录章节名称。

- 画面：公式字形、字号、标签遮挡、双语总高度、语言顺序、字幕与图形安全区。
- 动作：画面变化是否发生在对应解释期间；关键状态是否有停留；相机是否遮住需要辨认的关系。
- 声音：实际试听专有名词、数字、缩写、长句、章节接缝和结尾。记录试听方式及范围。没有音频感知能力时标记未试听。
- 混音：旁白可懂度、音乐遮蔽、呼吸感明显的避让、转场突变。数值测量注明测量的是 WAV 还是最终音轨。
- 同步：按同一语义锚点比较字幕、声音和图形；同时检查开头、中间和结尾，区分固定偏移与随时间增长的漂移。

数值工具只给观测；视觉语义与发音评价需要对应感知证据。不同语言独立审查，不能用一版结果替代另一版。

## 工程审查

1. 用技能的 `scripts/observe_timeline.py` 读取最终使用的时间轴，解释所有异常位置。输出的 overlap 是源区间重叠观测；结合播放器选取规则判断实际可见字幕是否冲突。
2. 核对源语音与脚本的对应关系；当前按序号命名的缓存不能仅凭文件存在证明有效。
3. 核对成片视频流、音频流、实际时长、帧率、尺寸和语言；分别检查音视频是否提前结束。
4. 对最终 MP4 完整解码音视频两条流，保存退出码与 stderr。
5. 查看编码后抽帧，而不只看录制前 Canvas。
6. 通过交付入口播放、跳转并切换语言，检查正确的视频与字幕路径。

## 返工范围

| 观察到的问题 | 最早检查处 | 修订后的最低复核范围 |
|---|---|---|
| 内容未解释就用于推理 | 分镜依赖 P1 | 相关章及后续引用该内容的章 |
| 只有英文版的中文翻译越界 | 译文/版式 P2/P5 | 英文版最长字幕与已修订位置；重录后的实际成片 |
| 换音色后越往后越不同步 | 实测语音、时间轴、倍率 P4/P6 | 全片时间轴，开中尾锚点和最终流时长 |
| 音乐过响，旁白文字与时长不变 | 混音 P4 | 新混音及最终音轨；原视频画面可复用 |
| MP4 能播放但末尾消失 | 捕获结束、流时长与截断 P6 | 完整解码和结尾连续片段 |

修订记录链接新输出及复核证据，随后将问题改为 resolved。证据不足时保持 unverified。若发现范围或接口必须改变，返回计划更新；不在修订中默默扩展整个项目。

## 交付结论

审查记录最后列出：当前成片路径及 SHA-256、各检查的证据位置、已关闭问题、尚未观察事项。工具读不进时间轴、片段缺失、主张错误或成片不可播放等会阻止对应产物验收；能够修复则继续修复。

最终答复区分“文件已生成”和“哪些质量项已验证”。不能将格式校验、文件存在或播放器短时启动描述成已完成全片内容和听感验收。

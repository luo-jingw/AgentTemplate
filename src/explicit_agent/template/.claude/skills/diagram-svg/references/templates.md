# 常见图型与模板

### 总览图（自上而下的多列数据流）

用于"整体结构"。每一列是一路输入（模态 / 分支），每一行是一个阶段：

```
输入（中性）→ 冻结编码（灰）→ 投影（整行中性框）→ 专属层（青，每列一个）
→ 共享主干（紫，整行框）→ 输出头（珊瑚）/ 丢弃（虚线）
```

同一阶段的框放在同一行、等高；多列共享的模块画成横跨整行的框。

### 模块内部图（两条分支并排）

用于"一个模块里面是什么"。顶部输入 → 公共预处理 → 左右两列分别画两条分支（如左紫：注意力；右青：MLP）→ 底部合并框写清合并公式 → 左侧虚线画残差。

### 条件 / 调制路径图（一分多）

顶部 2～3 个串联的中性框，底部用 L 形箭头分叉到 3 个并排的彩色框，表示同一信号供给不同模块。

### 输入编码图

左侧用矩形按比例拼出输入的空间布局（如多相机拼图），右侧接"编码器 → 输出形状"；底部用一排小方块表示时间维（条件帧青色，预测帧紫色），下方写数量。

### 矩阵对比图（注意力掩码等）

左右两个 3×3 网格，行 = 查询方，列 = 被看方；可见 = 实心紫，屏蔽 = 虚线空框；网格下方写名称与所属方法，图底一行说明读法。

### 计算量对比图（方块计数）

每行一个方法：左侧名称 + 一行配置，中间用一排方块表示前向次数（方块大小大致对应模型规模），右侧用粗体写延迟数字。

### 时间轴图

水平条表示时间，窄的珊瑚条表示计算，宽的青色条表示执行；下方画刻度轴。用于说明"一次预测覆盖多长时间"。

### 流程 / 阶段图

一行 4 个等宽框（宽 130，间距 26，x = 41, 197, 353, 509），左右箭头连接，每个框三行：编号 + 名称、两行要点。
